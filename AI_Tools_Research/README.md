# AI Tools and Research

AI-related tools, research, templates and training material.

## Folders

- [`AI ICS OT IoT Threat Modeler`](./AI%20ICS%20OT%20IoT%20Threat%20Modeler) — `ics_threat_modeler.py`, an AI-assisted threat modeling tool for ICS, OT and IoT targets, with its user manual, sample threat model reports, prompts, agents and agent run logs.
- [`AIpentest_sampleOutput`](./AIpentest_sampleOutput) — sample output from AIpentest (reports, session files and dashboard).
- [`Design Requirements Templates`](./Design%20Requirements%20Templates) — ISA/IEC 62443 SL-T 3 URS, FRS, SDS and HDS templates (Word and PDF) for a modular cooling plant integrated with a building management system.
- [`Training and Awareness`](./Training%20and%20Awareness) — the ICS/OT/IoT cyber-physical "Spot the Issue" catalog and protocol training slides. See that folder's README.
