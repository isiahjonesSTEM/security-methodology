# Agents

Export of the original Agent.ai threat modeling agent that `ics_threat_modeler.py` replaces, kept for reference and reuse on other agent platforms.

## Files

- `index.csv` — list of exported agents (ID, name, type, status, created date, folder).
- `HUBSPOT_AGENT_HUB.txt` — explains how the Agent.ai workflow (an ordered list of actions) was converted into a HubSpot Agent Hub agent (instruction-led, with enabled tools).

## Folders

- [`iot-ot-ics-threatmodeler--gz8gc95xp8lxuj9l`](./iot-ot-ics-threatmodeler--gz8gc95xp8lxuj9l) — the `IoT_OT_ICS_ThreatModeler` agent itself.
