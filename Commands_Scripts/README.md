# Commands and Scripts

Command references and scripts for security testing, assessment and acceptance testing.

## Files

| File | Description |
|---|---|
| `ReadOnlyEnumv3.py` | ReadOnlyEnum v3.0.0 — native Python, read-only enumeration and configuration audit tool for ICS/OT/IoT, IT, cloud, AI and cyber-physical systems. Protocol checks are implemented in the Python standard library with no external tool dependencies. Built for assurance testing, system V&V and acceptance testing.
