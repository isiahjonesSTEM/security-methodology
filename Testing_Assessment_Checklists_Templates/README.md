# Testing, Assessment, Checklists and Templates

Templates, checklists, workbooks and tools for ICS/OT/IoT cyber-physical security assessments, acceptance testing (FAT/SAT), threat modeling, governance and system security plans. Most are open source; the ICSOTpentest tool in its subfolder is a commercial product.

## Scoping, statements of work and request lists

| File | Description |
|---|---|
| `ICS OT IoT Security Risk Assessment Scope Template_Oct2025.docx` | Security risk assessment scope template. |
| `Security FAT SAT Scope of Work Template_Oct2025.pdf` | Security FAT/SAT scope of work template. |
| `ICS OT IoT Threat Modeling Attack Mapping SOW Template.pdf` | Threat modeling and attack mapping statement of work template. |
| `Reverse Engineering ICS ATTACK ISA IEC 62443 part 4-2 mapping Scope of Work Template.pdf` | Reverse engineering with MITRE ATT&CK for ICS and ISA/IEC 62443-4-2 mapping — scope of work template. |
| `Pre Assessment Request List` | Information and contacts to request before an onsite assessment. |
| `ICS Network and Asset Questions.docx` | Network and asset discovery questions. |
| `ICS OT Security Review Questions` | Security review questions by area (architecture and network, and more). |
| `ICS OT IoT Securt Test Lab Equipment Cost Estimate List Template.xlsx` | Test lab equipment cost estimate template. |
